# retail-price-parsers

Парсеры цен и каталогов четырёх российских продуктовых сетей: Дикси, Магнит,
Пятёрочка и Самокат. Собирают список товаров по магазину/региону, карточки
(название, бренд, цена, скидка, фасовка, наличие) и выгружают их в JSONL/CSV.

## Подход

HTTP-слой построен на `curl_cffi`/`httpx` с имитацией TLS- и HTTP/2-отпечатка
браузера — это обходит фильтрацию Qrator и ServicePipe, которые режут обычный
Python-клиент по JA3. Разбор HTML — `selectolax`/BeautifulSoup, данные часто
лежат в JSON-LD или блоке `window.__NUXT__`. Для прогрева сессий и JS-челленджей
есть Playwright-fallback. Регион задаётся контекстом магазина (cookies/shopCode/
SAP-код/showcase ID). Для Самоката, закрытого ServicePipe, собраны вспомогательные
скрипты перехвата заголовков мобильного приложения через mitmproxy на телефоне.

## Структура

- `grocery/` — Дикси, Магнит, Пятёрочка (sitemap -> карточки) и заметки по разведке
  `STORE_NOTES.md`;
- `magnit/` — пайплайн Магнита: сбор ссылок, фильтрация, парсинг, выгрузка в CSV;
- `samokat/` — исследование и обход защиты Самоката (мобильный трафик, прокси).

## Настройка и запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # подставьте прокси и региональные параметры
python magnit/parse_products.py
python grocery/dixy/parser.py --limit 100 --workers 8
```

Все секреты (прокси, токены, store ID) берутся из переменных окружения, в коде их нет.
